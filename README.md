# 🎓 Exercícios de Lógica: De Portugol para JavaScript

Este repositório foi criado para documentar a minha evolução nos estudos de lógica de programação. Aqui, peguei os exercícios propostos na faculdade (originalmente escritos em Portugol no meu caderno) e tomei a liberdade de traduzi-los para **JavaScript**, executando todos no ambiente **Node.js**.

O objetivo principal foi aplicar os conceitos acadêmicos em uma linguagem amplamente utilizada no mercado de trabalho, praticando a sintaxe moderna do JS e a manipulação de entradas/saídas no terminal.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **JavaScript (ES6+)**
* **Node.js** (Ambiente de execução)
* Módulo `node:readline/promises` (Para interação via terminal)

---

## 📂 Organização dos Exercícios

Abaixo está a lista dos exercícios resolvidos e estruturados no repositório:

| Exercício / Tema | Descrição Rápida | Arquivo Fonte |
| :--- | :--- | :--- |
| **01. Análise de clientes de uma loja** | Lê o nome dos clientes com mais de 60 anos, a quantidade de clientes que gastaram mais de R$500,00 e a média de idade dos clientes. | `[analise-clientes.mjs](./analise-clientes.mjs)` |

| **03. Sistema de consumo de Armazenamento de Memória** | Informa o total de armazenamento consumido, informa o total de clientes com consumo supeior a 500GB, informa o total de clientes com consumo igual ou até 500GB, informa a média de consumo de armazenamento dos clientes. | `[calculo-consumo-armazenamento.mjs](./calculo-consumo-armazenamento.mjs)` |
| **04. Sistema que Identifica o Número Maior** | Solicita dois números na entrada e informa qual o maior. | `[identificando-numero-maior.mjs](./identificando-numero-maior.mjs)` |
| **05. Sistema de Ordem Crescente** | Solicita três números inteiros e os organiza em ordem crescente. | `[numero-crescente.mjs](./numero-crescente.mjs)` |
| **06. Sistema do Número Cubo Raiz Quadrada** | Solicita dois números e informa o cubo do menor número e a raiz quadrada do maior número. | `[numero-cubo.mjs](./numero-cubo.)` |
