# 🎓 Exercícios de Lógica: De Portugol para JavaScript

Este repositório foi criado para documentar a minha evolução nos estudos de lógica de programação. Aqui, peguei os exercícios propostos na faculdade (originalmente escritos em Portugol no meu caderno) e tomei a liberdade de traduzi-los para **JavaScript**, executando todos no ambiente **Node.js**.

O objetivo principal foi aplicar os conceitos acadêmicos em uma linguagem amplamente utilizada no mercado de trabalho, praticando a sintaxe moderna do JS e a manipulação de entradas/saídas no terminal.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **JavaScript (ES6+)**
* **Node.js** (Ambiente de execução)
* Módulo `node:readline/promises` (Para interação via terminal)

---
